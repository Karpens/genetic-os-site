Embedded systems and input/output devices

Key points

  • An embedded system is a computer system built into a larger device to perform one dedicated function (or a small set of them), for example in a washing machine, microwave, car engine management unit or digital watch.
  • Most embedded systems are built around a microcontroller: a single chip containing a CPU, ROM/flash, RAM and input/output interfaces.
  • The program, called firmware, is stored in ROM or flash memory, which is non-volatile. It is not lost when the power is switched off, and the user usually cannot change it.
  • Typical features: small size, low cost, low power consumption, reliable, and often real-time (it must respond within a fixed short time, e.g. a car airbag controller).
  • Compared with a general-purpose computer (PC, laptop), an embedded system cannot run many different programs, has limited memory and processing power, and is hard to upgrade. In return it is cheap, efficient and dependable.
  • Examples examiners accept: traffic lights, central heating thermostat, smart meter, fitness tracker, car ABS and engine management, alarm systems, digital cameras, Internet of Things (IoT) devices.
  • The basic cycle is input → process → output. Sensors send data to the microcontroller, which runs the firmware and then controls outputs such as motors, heaters, lights or displays.
  • Input devices send data into a computer: keyboard, mouse, touchscreen, microphone, scanner, barcode reader, webcam and sensors (temperature, light, pressure, motion/infrared, ultrasonic, moisture).
  • Sensors usually produce analogue signals, so an analogue-to-digital converter (ADC) is needed before the CPU can process them. A digital-to-analogue converter (DAC) is used for analogue outputs such as a speaker.
  • Output devices present or act on processed data: monitor/LCD, LED, speaker, buzzer, printer (laser, inkjet), 3D printer, and actuators such as motors, heaters and valves that cause physical movement or change.
  • A capacitive touchscreen senses the electrical charge of a finger and supports multi-touch. A resistive screen senses pressure on layers and works with a gloved hand or stylus.
  • Choose devices to fit the context in exam answers, e.g. a light sensor for automatic street lights, or a pressure sensor in a burglar alarm mat.

In more detail

  • Worked washing machine: inputs: water level sensor, temperature sensor and buttons; processing: a microcontroller runs the chosen cycle; outputs: motor, heater, pump and display.
  • Worked sensor choice: greenhouse → temperature and humidity sensors; parking aid → ultrasonic sensor; burglar alarm → passive infrared (PIR) motion sensor.
  • Worked ADC: a temperature sensor gives 0–5 V, and an 8-bit ADC turns this into a number from 0 to 255.
  • Embedded vs general purpose: a microwave's controller runs one program stored in firmware; a laptop runs many programs and you can install new ones.

Practice

Embedded systems and input/output devices: 10 questions

Pick an answer to check it, or open the answer for the explanation.

1. Which of these is an example of an embedded system?

  1. A file server in a school
  2. A laptop running a word processor
  3. A microcontroller controlling a microwave oven
  4. A desktop PC used for gaming
Show answer

C: A microcontroller controlling a microwave oven. An embedded system is built into a larger device to do a dedicated job. The microwave's controller does only that, unlike general-purpose PCs, laptops and servers.

2. Where is the firmware of an embedded system normally stored?

  1. In the CPU cache
  2. In RAM, so it can be changed quickly
  3. In virtual memory on a hard disk
  4. In ROM or flash memory, so it stays when power is off
Show answer

D: In ROM or flash memory, so it stays when power is off. Firmware must survive power loss, so it is held in non-volatile ROM or flash. RAM and cache are volatile and would lose the program.

3. Which is a typical characteristic of an embedded system compared with a general-purpose computer?

  1. It performs a dedicated task using limited resources
  2. It can run many different applications at once
  3. It always has a keyboard and monitor
  4. It needs a large hard disk
Show answer

A: It performs a dedicated task using limited resources. Embedded systems are designed for one specific function, with small memory, low power and low cost. They are not built to run varied software.

4. A washing machine uses a thermistor to measure water temperature. The thermistor is a…

  1. sensor, which is an input device
  2. storage device
  3. output device
  4. processor
Show answer

A: sensor, which is an input device. A thermistor is a temperature sensor. It sends data into the controller, so it is an input device.

5. Which component in a car is an actuator?

  1. A motor that locks the doors
  2. A parking distance sensor
  3. A light sensor for the headlights
  4. A microphone for hands-free calls
Show answer

A: A motor that locks the doors. An actuator is an output device that causes physical movement. The door-lock motor is controlled by the system, whereas the others are inputs.

6. Which statement about touchscreens is correct?

  1. Resistive screens cannot detect pressure
  2. Capacitive screens work with any plastic stylus
  3. Resistive screens need a conductive finger
  4. Capacitive screens detect a finger's electrical charge and allow multi-touch
Show answer

D: Capacitive screens detect a finger's electrical charge and allow multi-touch. Capacitive screens sense the charge from a conductive finger and handle multi-touch. Resistive screens respond to pressure, so stylus or gloves work.

7. A sensor in a data logger takes 4 readings per second. Each reading uses 2 bytes. How many bytes are stored in 1 hour?

  1. 28 800 bytes
  2. 7 200 bytes
  3. 57 600 bytes
  4. 14 400 bytes
Show answer

A: 28 800 bytes. 1 hour = 3600 s. 4 × 3600 = 14 400 readings. 14 400 × 2 bytes = 28 800 bytes.

8. Which sensor is most suitable for switching street lights on automatically at dusk?

  1. Pressure sensor
  2. Moisture sensor
  3. Light sensor
  4. Sound sensor
Show answer

C: Light sensor. A light sensor measures ambient brightness. The controller switches the lamps on when the reading falls below a set level.

9. Why is an analogue-to-digital converter (ADC) often needed in an embedded system?

  1. To increase the screen resolution
  2. To convert the analogue signals from sensors into digital data
  3. To make the CPU run faster
  4. To store firmware in ROM
Show answer

B: To convert the analogue signals from sensors into digital data. Sensors measure real-world quantities as analogue signals. The microcontroller only processes digital binary data, so an ADC converts them.

10. Which is a disadvantage of an embedded system?

  1. It uses far more power than a PC
  2. It is usually expensive to mass-produce
  3. It is hard to upgrade or change because the firmware is fixed
  4. It cannot be programmed at all
Show answer

C: It is hard to upgrade or change because the firmware is fixed. Firmware in ROM and the fixed hardware make upgrades difficult. Embedded systems are usually cheap and low-power, which are advantages.

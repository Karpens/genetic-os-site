Networks and protocols

Key points

  • A LAN covers a small geographic area (a home, school); a WAN covers a large area, such as the internet.
  • Client-server networks use a central server; peer-to-peer networks share resources directly between devices.
  • Topologies: a star topology connects every device to a central switch; a mesh topology connects devices to many others, giving redundancy.
  • Protocols are rules for communication: TCP/IP (packet transmission and addressing), HTTP/HTTPS (web pages), SMTP/IMAP (email), FTP (file transfer).
  • Data is split into packets with a header (addresses) and payload; packets can take different routes and are reassembled at the destination.
  • Network performance is affected by bandwidth, number of users, interference and the transmission medium (wired is usually faster and more reliable than wireless).

In more detail

  • Worked packets: a 1 MB file sent in packets of 1500 bytes needs about 670 packets, each with source and destination addresses and a sequence number for reassembly.
  • Worked bandwidth: a 100 Mbps link can send a 50 MB file in about 50 × 8 ÷ 100 = 4 seconds, ignoring overheads.
  • Worked protocols: HTTPS for secure web pages; SMTP to send email; IMAP to keep email synced on a server; FTP to transfer files.
  • Star vs mesh: in a star, one cable failure affects only one device but a switch failure takes down the network; a mesh has many routes, so it is robust but expensive.

Networks and protocols: 10 questions

Pick an answer to check it, or open the answer for the explanation.

1. What is an IP address used for?

  1. Storing passwords
  2. Identifying a device on a network
  3. Speeding up the CPU
  4. Compressing data
Show answer

B: Identifying a device on a network. Packets are routed using IP addresses.

2. What is the difference between a LAN and a WAN?

  1. A LAN covers a small area; a WAN covers a large geographic area
  2. A WAN is always wireless
  3. A LAN has no switches
  4. They are the same
Show answer

A: A LAN covers a small area; a WAN covers a large geographic area. The internet is the largest WAN.

3. Which protocol is used for secure web pages?

  1. FTP
  2. SMTP
  3. HTTPS
  4. IMAP
Show answer

C: HTTPS. HTTPS encrypts data between browser and server.

4. What is in a packet header?

  1. Only the message content
  2. Addressing and sequencing information
  3. The whole file
  4. Nothing
Show answer

B: Addressing and sequencing information. This lets packets be routed and reassembled in order.

5. What is an advantage of a mesh topology?

  1. It uses the least cabling
  2. Multiple routes give redundancy if one link fails
  3. It needs no devices
  4. It is always wireless
Show answer

B: Multiple routes give redundancy if one link fails. There's no single point of failure.

6. What is the role of a router?

  1. To store files
  2. To direct data packets between networks
  3. To display web pages
  4. To encrypt passwords
Show answer

B: To direct data packets between networks. Routers use IP addresses to forward packets.

7. Which protocol is used to transfer email between servers?

  1. HTTP
  2. SMTP
  3. FTP
  4. TCP only
Show answer

B: SMTP. IMAP and POP are used to retrieve mail.

8. What is an advantage of a star topology?

  1. One failure stops the whole network
  2. If one cable fails, only that device is affected
  3. No central device needed
  4. It uses the least cabling
Show answer

B: If one cable fails, only that device is affected. The central switch is the main point of failure.

9. Which protocol lets a user read email stored on a mail server from several different devices?

  1. SMTP
  2. FTP
  3. IMAP
  4. HTTPS
Show answer

C: IMAP. IMAP keeps messages on the server so many devices can view them. SMTP is for sending email, and FTP is for file transfer.

10. A web designer uploads website files to a hosting company's server. Which protocol is designed for this?

  1. HTTP
  2. FTP
  3. SMTP
  4. IMAP
Show answer

B: FTP. FTP (File Transfer Protocol) is designed for moving files between computers. HTTP is mainly used to request web pages.

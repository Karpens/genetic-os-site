First-order differential equations: the integrating factor

Key points

  • A first-order linear differential equation has the form dy/dx + P(x)y = Q(x).
  • Multiply through by the integrating factor I(x) = e^(∫P dx). The left side becomes d/dx(I y), so I y = ∫I Q dx, then divide by I.
  • Example: dy/dx + 2y = e^(−x): I = e^(2x); d/dx(e^(2x)y) = eˣ; e^(2x)y = eˣ + c; y = e^(−x) + ce^(−2x).
  • The general solution includes the constant c; a particular solution uses a boundary condition to find c.
  • If the equation is not in standard form (for example x dy/dx + y = x²), divide by the coefficient of dy/dx first.

In more detail

  • Worked example: dy/dx − y tan x = cos x: I = e^(∫−tan x dx) = cos x; d/dx(y cos x) = cos²x; y cos x = x/2 + (sin 2x)/4 + c.
  • Modelling: Newton's law of cooling dT/dt = −k(T − T₀) is first order and can be solved by separating variables or with an integrating factor.
  • Exam tip: always check the coefficient of dy/dx is 1 before finding the integrating factor.

First-order differential equations: the integrating factor: 10 questions

Pick an answer to check it, or open the answer for the explanation.

1. What is the integrating factor for dy/dx + 3y = x?

  1. e^(x)
  2. 3x
  3. e^(x²)
  4. e^(3x)
Show answer

D: e^(3x). e^(∫3 dx).

2. What is the integrating factor for dy/dx + (1/x)y = x (x > 0)?

  1. e^x
  2. x
  3. ln x
  4. 1/x
Show answer

B: x. e^(ln x) = x.

3. After multiplying by I(x), the left side becomes …

  1. d/dx(I y)
  2. I dy/dx
  3. dy/dx
  4. I y
Show answer

A: d/dx(I y). That is why it works.

4. Solve dy/dx + 2y = 0.

  1. y = ce^(2x)
  2. y = 2x + c
  3. y = ce^(−2x)
  4. y = c
Show answer

C: y = ce^(−2x). Separable or I = e^(2x).

5. Put x dy/dx + 2y = x³ into standard form.

  1. dy/dx + 2y = x³
  2. dy/dx + 2xy = x⁴
  3. x dy/dx = x³ − 2y
  4. dy/dx + (2/x)y = x²
Show answer

D: dy/dx + (2/x)y = x². Divide by x.

6. For dy/dx + (2/x)y = x², what is the integrating factor?

  1. e^(2x)
  2. x²
  3. 2 ln x
  4. 1/x²
Show answer

B: x². e^(2 ln x) = x².

7. Solve dy/dx + (2/x)y = x².

  1. y = x³/5 + c/x²
  2. y = x³ + c
  3. y = x⁵/5 + c
  4. y = cx²
Show answer

A: y = x³/5 + c/x². d/dx(x²y) = x⁴, so x²y = x⁵/5 + c.

8. What distinguishes a particular solution from the general solution?

  1. It has no x
  2. It is always zero
  3. A boundary condition fixes the constant
  4. It uses a different method
Show answer

C: A boundary condition fixes the constant. c is found from the given condition.

9. dy/dx + y = 1 with y = 0 when x = 0. What is y?

  1. e^(−x)
  2. 1 + e^(−x)
  3. x
  4. 1 − e^(−x)
Show answer

D: 1 − e^(−x). y = 1 + ce^(−x), c = −1.

10. Which equation is first-order linear?

  1. (dy/dx)² + y = 0
  2. dy/dx + x²y = sin x
  3. dy/dx = y²
  4. d²y/dx² + y = 0
Show answer

B: dy/dx + x²y = sin x. y and dy/dx appear to the first power only.

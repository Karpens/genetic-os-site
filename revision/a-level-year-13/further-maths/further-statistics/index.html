Continuous random variables: pdf, cdf, expectation and variance

Key points

  • A probability density function (pdf) f(x) satisfies f(x) ≥ 0 and ∫f(x) dx = 1 over the whole range; P(a < X < b) = ∫ₐᵇ f(x) dx.
  • The cumulative distribution function (cdf) F(x) = P(X ≤ x) = ∫ f(t) dt from the lower end to x; f(x) = F′(x).
  • Median m: F(m) = 0.5. Quartiles: F(q₁) = 0.25, F(q₃) = 0.75. Mode: where f is greatest.
  • E(X) = ∫x f(x) dx, Var(X) = ∫x² f(x) dx − [E(X)]²; E(g(X)) = ∫g(x) f(x) dx.
  • The continuous uniform (rectangular) distribution on [a, b]: f(x) = 1/(b − a), E(X) = (a + b)/2, Var(X) = (b − a)²/12.

In more detail

  • Worked example: f(x) = (3/8)x² on 0 ≤ x ≤ 2. E(X) = ∫(3/8)x³ dx = 1.5; E(X²) = ∫(3/8)x⁴ dx = 2.4; Var(X) = 2.4 − 2.25 = 0.15.
  • Piecewise pdfs: integrate each piece over its own interval and add; the cdf must be continuous.
  • Exam tip: sketch the pdf first; it shows the mode and whether the mean is above or below the median.

  1. 1/3
  2. 9
  3. 1/9
  4. 1/27

C: 1/9. k × 27/3 = 1 gives k = 1/9.

3. How is the pdf found from the cdf?

  1. Integrate
  2. Differentiate: f(x) = F′(x)
  3. Square it
  4. Take the reciprocal
Show answer

B: Differentiate: f(x) = F′(x). The cdf is the integral of the pdf.

4. How is the median m defined for a continuous random variable?

  1. f(m) = 0.5
  2. m = E(X)
  3. f(m) is maximum
  4. F(m) = 0.5

D: F(m) = 0.5. Half the probability lies below m.

  1. 6
  2. 36
  3. 3
  4. 1

C: 3. 36/12.

7. For f(x) = 2x on 0 ≤ x ≤ 1, what is E(X)?

  1. 1/2
  2. 2/3
  3. 1
  4. 1/3

B: 2/3. ∫2x² dx = 2/3.

8. For f(x) = 2x on 0 ≤ x ≤ 1, what is the cdf F(x)?

  1. 2x
  2. x
  3. 1 − x²
  4. x²

  1. 1/√2
  2. 1/2
  3. 2/3
  4. 1/4

A: 1/√2. x² = 0.5.

Conditional probability and the normal distribution

Key points

  • Conditional probability: P(A|B) = P(A ∩ B) ÷ P(B). Events are independent if P(A|B) = P(A).
  • Venn diagrams and tree diagrams help model conditional situations.
  • The normal distribution X ~ N(μ, σ²) is symmetrical about the mean, with about 68% of data within 1 standard deviation and 95% within 2.
  • Standardising uses Z = (X − μ) ÷ σ to convert to the standard normal distribution.
  • A binomial distribution can be approximated by a normal distribution when n is large and p is close to 0.5.

In more detail

  • Worked standardising: X ~ N(50, 16) → σ = 4 → P(X < 56) = P(Z < 1.5) = 0.9332.
  • Worked interval: P(46 < X < 54) = P(−1 < Z < 1) = 0.6827.
  • Worked rule of thumb: about 95% of values lie within μ ± 2σ, here 42 to 58.
  • Worked conditional: P(X > 54 | X > 50) = P(X > 54) ÷ P(X > 50) = 0.1587 ÷ 0.5 = 0.317.
  • Worked approximation: B(100, 0.5) can be approximated by N(50, 25).

Conditional probability and the normal distribution: 10 questions

Pick an answer to check it, or open the answer for the explanation.

1. What does P(A|B) mean?

  1. The probability of A and B
  2. The probability of A given B has occurred
  3. The probability of A or B
  4. The probability of neither
Show answer

B: The probability of A given B has occurred. P(A|B) = P(A ∩ B) ÷ P(B).

2. For a normal distribution, what is P(X < μ)?

  1. 0
  2. 0.25
  3. 0.5
  4. 1
Show answer

C: 0.5. The distribution is symmetrical about the mean.

3. Approximately what percentage of normally distributed data lies within 2 standard deviations of the mean?

  1. 50%
  2. 68%
  3. 95%
  4. 99.9%
Show answer

C: 95%. About 95% falls within ±2σ.

4. What is the standardising formula for the normal distribution?

  1. Z = (X − μ) ÷ σ
  2. Z = X ÷ μ
  3. Z = μ − σ
  4. Z = (X + μ) ÷ σ
Show answer

A: Z = (X − μ) ÷ σ. This converts any normal variable to the standard normal.

5. Two events A and B are independent if:

  1. P(A|B) = P(A)
  2. P(A|B) = 0
  3. P(A ∩ B) = 0
  4. P(A) = P(B)
Show answer

A: P(A|B) = P(A). Knowing B has occurred doesn't change the probability of A.

6. P(A ∩ B) = 0.2 and P(B) = 0.5. What is P(A|B)?

  1. 0.1
  2. 0.4
  3. 0.7
  4. 0.25
Show answer

B: 0.4. 0.2 ÷ 0.5 = 0.4.

7. Approximately what percentage of normal data lies within 1 standard deviation of the mean?

  1. 50%
  2. 68%
  3. 95%
  4. 99%
Show answer

B: 68%. About two thirds of values.

8. X ~ N(50, 5²). What is the z-score of X = 60?

  1. 1
  2. 2
  3. 10
  4. 0.2
Show answer

B: 2. (60 − 50) ÷ 5 = 2.

9. Events A and B are independent with P(A) = 0.3 and P(B) = 0.6. What is P(A ∩ B)?

  1. 0.9
  2. 0.5
  3. 0.18
  4. 0.72
Show answer

C: 0.18. For independent events P(A ∩ B) = P(A) × P(B) = 0.3 × 0.6 = 0.18. Adding the probabilities (0.9) is a common error.

10. P(A) = 0.5, P(B) = 0.4 and P(A ∩ B) = 0.3. Which statement is correct?

  1. A and B are independent, because 0.3 < 0.4
  2. A and B are independent, because 0.3 < 0.5
  3. A and B are not independent, because 0.3 ≠ 0.5 × 0.4
  4. A and B are mutually exclusive, because P(A ∩ B) ≠ 0
Show answer

C: A and B are not independent, because 0.3 ≠ 0.5 × 0.4. Independence needs P(A ∩ B) = P(A)P(B) = 0.2. Since 0.3 ≠ 0.2 the events are not independent. They overlap, so they are not mutually exclusive either.

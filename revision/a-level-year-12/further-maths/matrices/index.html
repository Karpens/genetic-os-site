Matrix arithmetic: addition, multiplication and special matrices

Key points

  • Matrices of the same order can be added or subtracted entry by entry. Multiply by a scalar by multiplying every entry.
  • Matrix multiplication AB needs columns of A = rows of B; an m × n matrix times an n × p matrix gives m × p. Each entry is a row of A times a column of B.
  • Matrix multiplication is associative ((AB)C = A(BC)) but not commutative (AB ≠ BA in general).
  • The identity I has 1s on the leading diagonal and 0s elsewhere: AI = IA = A. The zero matrix has all entries 0.
  • Powers: A² = AA, A³ = AAA. Some matrices satisfy special properties such as A² = I (self-inverse).

In more detail

  • Worked example: find k if [[1, k], [0, 1]]² = [[1, 6], [0, 1]]: the top-right entry is 2k, so k = 3.
  • Proving AB ≠ BA: one counter-example with specific matrices is enough.
  • Exam tip: on a calculator, check matrix products, but show at least one entry's working in the exam.

Matrix arithmetic: addition, multiplication and special matrices: 10 questions

Pick an answer to check it, or open the answer for the explanation.

1. What is the order of AB if A is 2 × 3 and B is 3 × 4?

  1. 3 × 3
  2. 4 × 2
  3. Not possible
  4. 2 × 4
Show answer

D: 2 × 4. Rows of A × columns of B.

2. Can a 3 × 2 matrix be multiplied by a 3 × 2 matrix?

  1. Yes
  2. No
  3. Only if they are equal
  4. Only if both are square
Show answer

B: No. Columns (2) ≠ rows (3).

3. Calculate [[1, 2], [3, 4]] + [[0, −1], [5, 2]].

  1. [[1, 1], [8, 6]]
  2. [[1, 3], [−2, 2]]
  3. [[0, −2], [15, 8]]
  4. [[1, 1], [8, 2]]
Show answer

A: [[1, 1], [8, 6]]. Add corresponding entries.

4. Calculate [[1, 2], [3, 4]] × [[2, 0], [1, 1]].

  1. [[2, 0], [3, 4]]
  2. [[2, 4], [7, 4]]
  3. [[4, 2], [10, 4]]
  4. [[4, 2], [7, 6]]
Show answer

C: [[4, 2], [10, 4]]. Row 1: (2 + 2, 0 + 2); row 2: (6 + 4, 0 + 4).

5. Which property does matrix multiplication have?

  1. Commutative
  2. Both
  3. Neither
  4. Associative
Show answer

D: Associative. (AB)C = A(BC).

6. If A = [[0, 1], [1, 0]], what is A²?

  1. A
  2. I
  3. 0
  4. 2A
Show answer

B: I. Reflecting twice returns to the start.

7. What is 3[[2, −1], [0, 4]]?

  1. [[6, −3], [0, 12]]
  2. [[5, 2], [3, 7]]
  3. [[6, −1], [0, 4]]
  4. [[2, −3], [0, 12]]
Show answer

A: [[6, −3], [0, 12]]. Multiply each entry.

8. For a matrix A, what is AI?

  1. I
  2. 0
  3. A
  4. A²
Show answer

C: A. The identity leaves A unchanged.

9. If A is 3 × 3, what is the order of A²?

  1. 9 × 9
  2. 6 × 6
  3. 3 × 1
  4. 3 × 3
Show answer

D: 3 × 3. Square matrices can be squared.

10. Calculate [[2, 1], [0, 1]]².

  1. [[4, 1], [0, 1]]
  2. [[4, 3], [0, 1]]
  3. [[4, 2], [0, 1]]
  4. [[2, 2], [0, 2]]
Show answer

B: [[4, 3], [0, 1]]. Row 1: (4 + 0, 2 + 1).

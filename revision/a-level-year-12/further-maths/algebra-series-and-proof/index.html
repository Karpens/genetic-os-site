Roots of polynomials: relationships between roots and coefficients

Key points

  • For ax² + bx + c = 0 with roots α, β: α + β = −b/a and αβ = c/a.
  • For ax³ + bx² + cx + d = 0 with roots α, β, γ: Σα = −b/a, Σαβ = c/a, αβγ = −d/a.
  • For a quartic ax⁴ + bx³ + cx² + dx + e = 0: Σα = −b/a, Σαβ = c/a, Σαβγ = −d/a, αβγδ = e/a.
  • Useful identities: α² + β² = (α + β)² − 2αβ; 1/α + 1/β = (α + β)/αβ; α² + β² + γ² = (Σα)² − 2Σαβ.
  • To write an equation with given roots: x² − (sum)x + (product) = 0.

In more detail

  • Worked example: roots of x² − 5x + 3 = 0 are α, β. An equation with roots α², β² has sum α² + β² = 25 − 6 = 19 and product (αβ)² = 9: x² − 19x + 9 = 0.
  • Sign pattern: for a cubic the signs alternate: −b/a, +c/a, −d/a.
  • Exam tip: write the sums and products down before manipulating; never try to find the roots themselves unless asked.

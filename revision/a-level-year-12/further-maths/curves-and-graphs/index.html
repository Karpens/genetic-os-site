Rational functions: asymptotes and curve sketching

Key points

  • A rational function is a fraction of polynomials, such as y = (2x + 1)/(x − 3).
  • Vertical asymptotes occur where the denominator is zero (and the numerator is not): x = 3 above.
  • Horizontal asymptotes describe the behaviour as x → ±∞: for equal degrees, y → ratio of leading coefficients (y = 2 above); if the denominator's degree is higher, y → 0. An oblique asymptote occurs when the numerator's degree is one more than the denominator's (divide to find it).
  • To sketch: find intercepts (x = 0 and y = 0), asymptotes, the behaviour either side of vertical asymptotes, and any stationary points.
  • The range of y = (ax² + bx + c)/(dx² + ex + f) can be found by rearranging into a quadratic in x and requiring the discriminant ≥ 0.

In more detail

  • Worked example: y = (x² + 2)/(x − 1) = x + 1 + 3/(x − 1): vertical asymptote x = 1 and oblique asymptote y = x + 1.
  • Behaviour check: test a value just either side of a vertical asymptote to see whether y → +∞ or −∞.
  • Exam tip: label every asymptote with its equation and every intercept with coordinates on your sketch.

1. What is the vertical asymptote of y = (2x + 1)/(x − 3)?

  1. x = −3
  2. x = −1/2
  3. x = 3
  4. y = 2
Show answer

C: x = 3. The denominator is zero at x = 3.

2. What is the horizontal asymptote of y = (2x + 1)/(x − 3)?

  1. y = 2
  2. y = 0
  3. y = 3
  4. y = 1/3
Show answer

A: y = 2. Ratio of leading coefficients.

3. What is the horizontal asymptote of y = 5/(x² + 1)?

  1. y = 5
  2. y = 1
  3. None
  4. y = 0
Show answer

D: y = 0. The denominator grows faster.

4. Where does y = (x − 4)/(x + 2) cross the x-axis?

  1. (−2, 0)
  2. (4, 0)
  3. (0, −2)
  4. (0, 4)
Show answer

B: (4, 0). Numerator zero at x = 4.

5. Where does y = (x − 4)/(x + 2) cross the y-axis?

  1. (0, 4)
  2. (0, 2)
  3. (0, −2)
  4. (0, −4)
Show answer

C: (0, −2). −4/2 = −2.

6. Which function has an oblique asymptote?

  1. y = (x² + 1)/x
  2. y = (x + 1)/x
  3. y = 1/x²
  4. y = x/(x² + 1)
Show answer

A: y = (x² + 1)/x. Numerator degree one more: y = x + 1/x, asymptote y = x.

7. What are the vertical asymptotes of y = 1/((x − 1)(x + 2))?

  1. x = −1 and x = 2
  2. y = 0
  3. x = 1 only
  4. x = 1 and x = −2
Show answer

D: x = 1 and x = −2. Denominator zero.

8. As x → ∞, what does y = (3x² − x)/(x² + 4) approach?

  1. 0
  2. 3
  3. ∞
  4. −1/4
Show answer

B: 3. Leading coefficients 3/1.

9. How can you find the range of a rational function of two quadratics?

  1. Differentiate twice
  2. Find the y-intercept only
  3. Rearrange into a quadratic in x and use discriminant ≥ 0
  4. Use Pascal's triangle
Show answer

C: Rearrange into a quadratic in x and use discriminant ≥ 0. Real x requires a non-negative discriminant.

10. What does the curve do near a vertical asymptote?

  1. Tends to +∞ or −∞
  2. Crosses it
  3. Stops
  4. Becomes horizontal
Show answer

A: Tends to +∞ or −∞. y grows without bound.
